# CalebasseCalvasse — appli Android

Coquille native (Capacitor) du hub [calebassecalvasse.fr](https://calebassecalvasse.fr) :
elle affiche le site en ligne et programme les rappels en notifications
locales Android, fiables et hors-ligne. Aucune donnée dans ce dépôt — tout
vit sur le site et son serveur.
