# CalebasseCalvasse — appli Android

Coquille native (Capacitor) du hub [calebassecalvasse.fr](https://calebassecalvasse.fr) :
elle affiche le site en ligne (toujours à jour, rien à re-télécharger),
offre la connexion Google native, reçoit les notifications poussées (FCM)
même appli fermée, et se recharge d'un balayage vertical depuis le haut de
page. Aucune donnée dans ce dépôt — tout vit sur le site et son serveur.

**Télécharger :**
[dernière version de l'APK](https://github.com/Torvator/calebasse-app/releases/latest/download/calebassecalvasse.apk)
(signé, construit automatiquement par GitHub Actions).
